# Cinematic Carousel UI

A responsive React carousel with cinematic imagery, autoplay, keyboard controls, swipe navigation, reduced-motion support, and an accessible developer details modal. This app is included in the [React Mini Projects](https://github.com/a2rp/react_mini_projects) collection.

## Features

- Autoplay with pause and resume controls
- Previous, next, keyboard, swipe, and preview navigation
- Responsive cinematic layout with local image assets
- Accessible modal with focus handling and repository activity
- Fixed branded header, icon-only footer links, and a floating go-to-top control

## Tech stack

- React and Vite
- styled-components
- React Icons

## Run locally

From the repository root, install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

Open `/apps/cinematic-carousel-ui` in the running app.

## Build and deploy

Run `npm run build` and `npm run deploy` from the repository root. The app is available at [https://a2rp.github.io/react_mini_projects/apps/cinematic-carousel-ui/](https://a2rp.github.io/react_mini_projects/apps/cinematic-carousel-ui/).
