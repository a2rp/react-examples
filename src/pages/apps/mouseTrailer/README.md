# Mouse Trailer

Route: `/apps/mouse-trailer`

A cursor-following interaction demo adapted into the React Mini Projects collection. Hover over the image cards to see the trailer display contextual labels. The original HTML, CSS, JavaScript, assets, README, and license are retained in `source/` alongside the React route implementation.

The custom pointer is hidden on touch-first devices, and the go-to-top control respects the reduced-motion preference. The page is a front-end interaction example and does not send or store visitor data.
