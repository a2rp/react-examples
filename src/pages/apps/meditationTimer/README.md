# Quiet Hours: Meditation Timer

A focused breathing timer with guided rhythms, practice history, and a seven-day activity chart.

**Collection route:** [/apps/meditation-timer](https://a2rp.github.io/react_mini_projects/apps/meditation-timer)

## What it does

- Choose a 3, 5, 10, 15, or 20 minute session.
- Start, pause, resume, reset, or restart the timer.
- Follow easy breathing or four-part box breathing cues.
- Review daily and weekly practice totals.
- Remove individual sessions or clear the history with confirmation.

## Data and privacy

Completed sessions are stored in this browser. If browser storage is unavailable, the timer still works and session history lasts for the current page session. The app does not send session details to a server. Clearing browser site data removes the saved log. This timer is a general wellness tool and does not provide medical or mental health advice.

## Development

This project runs inside the React Mini Projects collection. From the repository root, run npm install and npm run dev, then open /apps/meditation-timer.
