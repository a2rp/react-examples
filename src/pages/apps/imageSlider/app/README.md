# Image Slider

A responsive React image slider with local image assets, manual navigation, slide indicators, captions, and optional autoplay.

## Features

- Responsive percentage-based slide movement
- Previous, next, and slide selection controls
- Optional autoplay that stops when the carousel receives focus or the pointer hovers over it
- Reduced-motion support for slide transitions and page scrolling
- Local image assets with accessible labels
- Fixed responsive header, icon-only footer links, and go-to-top button

## Tech stack

React, Create React App, Sass, and React Icons.

## Run locally

```bash
npm install
npm start
```

Create a production build with npm run build. The React Mini Projects collection publishes this app at https://a2rp.github.io/react_mini_projects/apps/image-slider/. Run deployment from the collection root; keep the original CRA deploy command only for a standalone repository.
