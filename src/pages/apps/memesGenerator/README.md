# Meme Generator

A focused image tool for browsing community-published Imgflip templates, adding captions, and saving the result as a PNG.

**Collection route:** [/apps/memes-generator](https://a2rp.github.io/react_mini_projects/apps/memes-generator)

## What it does

- Loads the current public templates from Imgflip.
- Adds editable top and bottom captions.
- Lets you save a finished meme as a PNG.
- Keeps caption text in your browser; it is not sent to Imgflip.

Templates are community-uploaded and may change. Review images before sharing.

## Development

This project runs inside the React Mini Projects collection. From the repository root, run npm install and npm run dev, then open /apps/memes-generator.
